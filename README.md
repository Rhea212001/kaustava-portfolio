# Kaustava Sarma - Writer Portfolio

Personal portfolio site for Kaustava Sarma, a writer, storyteller and content marketing specialist. A single-page React app.

## Sections

- Home: introduction and short bio card
- About
- Writing: three directions (storytelling, content marketing, research writing)
- Journey: work experience timeline
- Toolbox: skills
- Learning: education
- Previous works: YouTube scripts
- Highlights: published work and speaking engagements
- Contact

## Tech stack

- React 19
- Vite
- lucide-react for icons
- Google Fonts: Playfair Display, DM Sans, Caveat
- Plain CSS in `src/styles.css`

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production into `dist/`:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
